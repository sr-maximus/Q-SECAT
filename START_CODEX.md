# Inicio rápido para Codex

Este paquete contiene la versión base **Q-SECAT v0.1.0** y un encargo técnico completo para evolucionarla sin rehacer ni perder el trabajo existente.

## Cómo usarlo

1. Extraiga el ZIP.
2. Abra la carpeta `Q-SECAT-v0.1.0` como proyecto en Codex.
3. Entregue a Codex esta instrucción:

```text
Lee íntegramente codex/PROMPT_MASTER_QSECAT.md y ejecútalo sobre este repositorio. No te limites a explicar: inspecciona, modifica, valida, prueba y empaqueta el proyecto conforme a todos los criterios de aceptación. Conserva la autoría de Edwin Javier Peñuela Camacho y no inventes fuentes, estándares, vulnerabilidades ni resultados.
```

4. Codex debe comenzar leyendo, como mínimo:

- `README.md`
- `codex/PROMPT_MASTER_QSECAT.md`
- `codex/BASELINE.json`
- `codex/ACCEPTANCE_CRITERIA.md`
- `docs/Q-SECAT-whitepaper-es.md`
- `catalog/sources.yaml`
- `catalog/techniques.yaml`
- `catalog/controls.yaml`
- `catalog/tests.yaml`

## Resultado esperado de Codex

Una versión evolucionada y verificable del framework, con catálogos ampliados, fuentes comprobadas, trazabilidad completa, CLI mejorada, documentación bilingüe, pruebas automatizadas y un nuevo ZIP de publicación con sus sumas SHA-256.

> El proyecto es defensivo y de investigación. Toda prueba debe ejecutarse únicamente sobre sistemas propios o expresamente autorizados.
