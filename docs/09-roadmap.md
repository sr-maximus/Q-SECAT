# Project Roadmap

## Version 0.1 — Foundational community draft

- Define 12 domains, 12 tactics and 48 techniques.
- Publish controls, safe tests, risk model, schema and CLI.
- Establish citation, contribution and evidence rules.

## Version 0.2 — Evidence expansion

- Add technique references at item level.
- Add sector profiles for finance, critical infrastructure, government and research labs.
- Add provider/customer shared-responsibility profile.
- Add SARIF and CycloneDX CBOM import/export adapters.

## Version 0.3 — Testbed profiles

- Add simulator reference implementations for selected QSTEST procedures.
- Add QKD and QRNG evidence templates.
- Add reproducibility manifests for quantum-cloud backends.
- Add a safe laboratory profile reviewed by quantum hardware specialists.

## Version 0.4 — External mappings

- Review mappings with domain experts.
- Add NIST CSF/SP 800-53, ISO/IEC 27001 and Common Criteria crosswalks.
- Add explicit QATT&CK comparison without copying identifiers or text.

## Version 1.0 — Stable specification

Release only after public review, identifier stability, independent validation of the CLI/schema, multiple real-world authorized case studies and a documented governance model.

## Research backlog

- empirical scoring calibration;
- correlated/cascading risk modeling;
- quantum-network observability and incident response;
- security properties of distributed quantum computing;
- sensor spoofing and resilient metrology test patterns;
- composable assurance cases across classical and quantum components;
- privacy and IP protection in shared quantum execution;
- benchmark datasets that do not expose sensitive vendor details.
