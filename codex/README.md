# Carpeta de entrega para Codex

Esta carpeta no sustituye la documentación del framework. Contiene instrucciones para que Codex inspeccione y evolucione la línea base.

- `PROMPT_MASTER_QSECAT.md`: encargo técnico completo.
- `ACCEPTANCE_CRITERIA.md`: controles de terminación verificables.
- `BASELINE.json`: estado medido del paquete antes de la intervención de Codex.

La instrucción mínima para Codex es:

```text
Lee codex/PROMPT_MASTER_QSECAT.md y ejecútalo de extremo a extremo sobre este repositorio. Conserva la autoría, verifica todas las fuentes, no inventes resultados y no declares éxito sin ejecutar las pruebas.
```
