# Q-SECAT 0.1.0 — Community Draft

**Release date:** 2026-08-01<br>
**Creator and principal author:** Edwin Javier Peñuela Camacho

## Included

- 12 security domains (`QSD`)
- 12 adversary tactics (`QTA`)
- 48 techniques (`QTE`)
- 10 priority risks (`QST`)
- 48 verifiable controls (`QSC`)
- 48 safe tests (`QSTEST`)
- 6 assurance levels (`QAL`)
- 7 assessment profiles
- 27 source records
- JSON Schema, Python CLI, Dockerfile, GitHub Actions CI and automated tests
- Spanish white paper and Spanish/English README files

## Validation status

The release passes catalog traceability, assessment-schema validation, example scoring, package-data drift checks and the automated test suite. It remains a community draft and has not undergone independent domain-expert review or formal standardization.

## Compatibility

Python 3.11–3.13. Catalog and assessment identifiers introduced in this release should not be silently repurposed in later versions.
